# VibesTribe — Android app

Official APK downloads for the VibesTribe Android app (Studio included, works offline).

Grab the latest build from **Releases →** the asset `vibestribe.apk`, or use the
download page: <https://vibestribe.org/app>

- **Install:** open the APK, allow "install unknown apps" if asked, confirm
  Play Protect with "More details → Install anyway".
- **Updating:** install the new APK over the old one — your songs and sessions
  are kept. Uninstalling deletes them.
- **iOS:** not yet; coming through TestFlight later.

SHA-256 of the current build is listed on the release and on the download page
(`version.json`).
